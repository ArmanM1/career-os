# Career Source Discovery

Start with current targets, season, existing sources, yield, and source health.

- Prefer durable public sources and deterministic access.
- Evaluate relevance, update cadence, provenance, expected yield, authentication needs, and adapter strategy.
- Auto-propose high-confidence public sources; authenticated sources require one-time user enablement.
- Use configured browser profiles only for authorized read-only navigation, screenshots, and extraction.
- Deduplicate candidates before proposing a monitor.
- Create evidence for why the source is useful and how it should be monitored.
- Find similar sources when a configured source has high yield.
- Mark CAPTCHA, MFA, or expired sessions as `auth_required`.

Never post, message, follow, like, comment, purchase, register, or submit.
