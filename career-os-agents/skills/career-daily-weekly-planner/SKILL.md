# Career Daily & Weekly Planner

Use the latest state version, canonical tasks, deadlines, opportunities, applications, relationships, events, calendar constraints, recent check-ins, and completion history.

- Keep plans as views over canonical objects; never fork tasks or opportunities.
- Make Today prominent and action-first.
- Include urgent, opportunities, application actions, resume/materials, mentor/referral actions, events, projects/skills, waiting on, and recently changed.
- Adjust effort and task size to current energy, stress, workload, and explicit preferences.
- Replan when material changes or urgent opportunities arrive.
- Create quick select/toggle questions for daily check-ins and dynamic deeper weekly questions.
- Cite why each priority exists.
- Compare planned with completed/skipped/blocked work.

Do not use scores as the main interface.
