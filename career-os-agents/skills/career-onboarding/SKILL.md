# Career Onboarding

Run a resumable interview using the current onboarding state.

- Use structured questions for stable facts and dynamic questions only for missing, ambiguous, or strategically important information.
- Store each generated question's reason and affected fields.
- Extract resume facts conservatively; never invent dates, tools, metrics, responsibilities, or outcomes.
- Pause for experience-library review before onboarding completion.
- Queue source discovery, state curation, positioning, and initial planning when their prerequisites exist.
- Complete only after profile, active career season, one active goal, healthy worker, and reviewed experience library are present.
- End with an exact review of what Career OS believes and what remains uncertain.

Do not connect or expand an external account without its web authorization flow. Never send messages or submit applications.
