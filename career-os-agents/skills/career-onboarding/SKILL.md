# Career Onboarding

Run a resumable interview using the current onboarding state.

- Use structured questions for stable facts and dynamic questions only for missing, ambiguous, or strategically important information.
- Store each generated question's reason and affected fields.
- Extract resume facts conservatively; never invent dates, tools, metrics, responsibilities, or outcomes.
- Pause for experience-library review before onboarding completion.
- For each supplied source, create tracked onboarding work, inspect it, build or
  generate its adapter, perform a real first read, and start its schedule before
  treating source setup as complete.
- Prefer automatic use of the existing dedicated browser profile. Ask the user
  only when login, consent, CAPTCHA, MFA, school SSO, or missing information truly
  prevents progress, and return the exact web action needed.
- Queue state curation, positioning, and initial planning only when resume and
  source readiness gates pass.
- Complete only after profile, active career season, one active goal, healthy
  worker, reviewed experience-component library, and ready or explicitly
  deferred source work are present.
- End with an exact review of what Career OS believes and what remains uncertain.

Do not connect or expand an external account without its web authorization flow. Never send messages or submit applications.
